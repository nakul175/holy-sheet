# HOLY-3 additional editor checkpoint

Production access remains disabled. This batch improves the existing foundation; HOLY-3 is not Done.

- Language grammars load asynchronously. Highlight completion only updates decorations and never document data, save state or Undo history. Failed/late grammar loads leave exact text usable. Blocks above 20,000 characters or 500 lines remain plain text with a language label. These are conservative implementation guards, not measured p95 performance acceptance.
- A single pasted/dropped supported file opens a review/upload dialog with explicit placement and required image alternative text. Multiple files and unsupported types are rejected with an explanation before content changes. Images/files are added only after server verification. The captured destination is checked again before insertion, so a removed/changed block or lost editing permission cannot silently redirect an upload.
- Replacement keeps the original node/object until verification, preserves the block identity and applies one isolated Undo transaction. A stale destination fails without overwriting newer content. Shared references receive no false quota-removal credit. Competing replacements serialize; cancelled reservations free quota. File blocks provide a keyboard-accessible action selector.
- Reservation operation IDs survive ambiguous responses within the open dialog. Duplicate submit is guarded; cancellation, changed selections, late responses, network errors and request timeouts retain truthful state. Pending file bytes are still memory-only: encrypted recovery across reload remains outstanding and is not claimed here.
- Find includes current authorized page-reference/file metadata labels without copying them into the document or persistent index. Focus refresh clears stale labels and ignores out-of-order responses. Inaccessible labels disappear from matches. Atomic file/reference navigation targets the rendered block and can open collapsed ancestors.
