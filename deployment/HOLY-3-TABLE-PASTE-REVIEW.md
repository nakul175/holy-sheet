# HOLY-3 reviewed table and literal paste checkpoint

HTML table and TSV paste now opens a review without modifying the page. The complete source text is available in a scrollable read-only field. Users can review filling a selected table, inserting independent tables split at 100 rows, or inserting complete literal text. Fill reports destination coordinates, result dimensions and occupied-cell replacement count. It expands only within 100 rows/20 columns and preserves destination cell identities, existing headers and widths. Excess columns use the explicit complete-literal-text path rather than clipping or pretending column splitting exists.

HTML is sanitized before source DOM/schema parsing. Rich supported cell content is retained; merged cells are explicitly unmerged with original text in the first cell and empty covered positions. Nested/unsupported cell blocks become disclosed readable cell text. Mixed surrounding document/table text uses a complete literal fallback instead of extracting and losing surrounding text. Source spans, sparse rectangular padding and cell counts are checked before expanded allocation; at most 10,000 logical source cells are parsed. Full document byte/block/depth/schema validation runs before mutation, so a source fitting the parser may still require literal text or a smaller source when the destination document exceeds its own budget.

Malformed quoted TSV falls back without dropping original text. Quoted tabs/newlines/escaped quotes, CRLF and Unicode are supported. Clipboard variants that supply raw HTML as their text flavour get a readable sanitized fallback. Hidden tracking text is removed for hidden/aria-hidden and inline display, visibility, zero opacity/font-size cases. No remote source is fetched.

All modes bind the original document/selection, reject stale or read-only application, revalidate before dispatch and isolate one Undo transaction. Literal mode preserves tabs/line breaks with no inherited marks, automatic links or tables. It is available through Cmd/Ctrl+Shift+V where browser paste events permit and an explicit manual-input control that does not require clipboard-read permission. Code-block paste stays literal. Upload file paste/drop keeps its existing reviewed workflow.

Evidence: fourteen new source/plan tests cover quoting, jagged padding, malformed fallback, merged/nested/mixed HTML, active markup/remote images, expansion bombs, fill/replacement/IDs/Undo, 201-row splitting, excess columns, stale/read-only guards and literal selection/mark behavior. Existing sanitizer regression now includes inline hidden tracking styles. Combined candidate: 283 local tests, ten real PostgreSQL integration tests, six real ClamAV tests, typecheck/build passed. All 16 default integration skips were run separately against the real services.
