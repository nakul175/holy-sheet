# Guarded keyboard and cell transform entry points

Paragraph/H1/H2/H3, numbered/bulleted/checklist and quote shortcuts now route through the reviewed transform planner instead of the default formatting commands. Safe conversions apply as one Undo step. Checked-marker removal or child lifting opens the captured preview before mutation. Unsupported code/media/table extraction reports a clear refusal without changing content. Matching active heading/list/quote shortcuts toggle through paragraph semantics; IME and AltGraph input remain untouched. Native code and shifted-symbol/key-code variants are handled.

The table-cell checklist control uses the same planner and exposes its active state accurately. Removing its checklist marker requires review; permitted paragraph-to-checklist conversion preserves cell text and the table schema. Captured preview state clears on close/logout.

Evidence: 18 shortcut cases cover both Meta/Ctrl variants, active toggles, shifted/legacy key data and IME/AltGraph exclusion, in addition to the 69 existing transform matrix/boundary cases. Combined local regression: 309 passed; typecheck/build passed. The unchanged server paths most recently passed ten real PostgreSQL and six scanner checks in the cleanup candidate. Browser rehearsal verified actual Cmd+Shift+9 warning/Cancel with checked state preserved, cell checklist insertion and warning/Cancel on removal, and actual Cmd+Alt+1 refusing code conversion while its TypeScript language/text remained unchanged and saved. Synthetic cell changes were undone afterward. Screenshots in surrounding workspace: outputs/holy-sheet/overnight-20261026/HOLY-3-keyboard-transform-warning.png and HOLY-3-cell-toggle-warning.png.

Full supported browser/mobile/a11y/performance qualification and structural discussion/task-binding identity behavior remain open; this is not full AC25 or story acceptance. No live collaboration or integration capability is claimed. Production remains disabled.
