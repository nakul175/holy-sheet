# HOLY-3 reviewed block transforms checkpoint

The Block → Turn into action now opens a review dialog for paragraph, H1/H2/H3, bulleted item, numbered item, checklist item and quote. Planning and schema validation do not mutate the editor. Confirmation checks the source fingerprint/current editability, applies one isolated history transaction and retains the selected logical block ID, inline text, compatible marks and links. A stale preview is rejected. Unsupported code/media/table or multi-block extraction is refused rather than silently flattened.

For a selected list item or quote, the logical unit is its owning item/quote when editing its first text block. Transforming to an ordinary text block lifts later child blocks immediately afterward with their IDs/content retained and a reviewed warning. Compatible list/quote destinations keep the children inside. Surrounding list siblings retain item IDs; an ordered suffix keeps its ordinal start. Checklist-to-checklist is a no-op preserving checked state; leaving checklist semantics explicitly warns that its marker is removed and Undo restores it. The removed structural inner paragraph ID is not separately retained when unwrapping to a single text node; discussion-anchor behavior for that structural identity change remains a cross-story qualification gate.

Shared validation now uses TextEncoder for identical UTF-8 byte bounds in browser and server. Canonical editor normalization is extracted into a shared pure module and removes Tiptap's null link-title and null/decimal ordered-list style defaults that previously caused otherwise-supported saves to fail. Unsupported non-default list styles remain rejected; safe links and text are kept. No server schema allowlist was broadened.

Evidence: 64 source/destination matrix cases cover all supported directions with text/marks/link/logical identity preservation and one-step Undo. Five additional transform cases cover child lifting, sibling IDs/numbering, stale/Viewer refusal, unsupported code/multi-block selection and table-cell constraints. Three canonicalization regressions cover link/list defaults, unsupported styles and Unicode validation without a Node Buffer global. Combined candidate: 269 local tests, ten real PostgreSQL tests, typecheck/build passed. Browser rehearsal verified checked-marker warning, Cancel preserving the checked item, confirmed conversion to a saved paragraph and one Undo restoring its checked checklist state. Keyboard and table-cell checklist conversions now use the guarded planner, with focused tests and native-browser evidence in HOLY-3-TRANSFORM-SHORTCUTS-REVIEW.md. Reviewed table paste is also implemented in HOLY-3-TABLE-PASTE-REVIEW.md. Remaining: alternate inner text-block guidance, structural comment/SHO binding identity integration, mobile/browser/accessibility/performance and the full HOLY-3 acceptance catalogue. This checkpoint does not complete AC25 or HOLY-3 release acceptance. Production feature remains disabled.
